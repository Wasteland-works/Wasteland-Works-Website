Protected downloads

Upload the large file to a release in the private downloads repository, then add its release asset details here.

How to upload a protected file
  1. Open the private Wasteland Works downloads repository.
  2. Select Draft a new release.
  3. Enter a version tag and release title, such as cascade-failure-v0.1.
  4. Drag the ZIP, installer or other project file into the release, wait for it to finish uploading, then select Publish release.
  5. Copy the uploaded file's numeric GitHub release asset ID. If you cannot find it, copy the release-page address and ask the website developer to retrieve it.
  6. Enter that number in Release asset ID below, then provide the name visitors should see.
  7. Choose the lowest membership level allowed to download the file and select Add protected download.
  8. Use Test download after it appears below to confirm everything works.

The original file stays private on GitHub. The website checks the member's access before creating a short-lived download link.

Access is controlled centrally by membership tier. Removing an entry here does not delete the original release file.
