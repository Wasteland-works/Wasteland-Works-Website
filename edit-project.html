Protected downloads

Prepare the download here, then publish one matching GitHub release. The website will find and connect the release file automatically.

Automatic upload instructions
  1. Enter the GitHub release tag, exact file name and membership level below.
  2. Select Prepare automatic download. The project will show that it is awaiting its GitHub release.
  3. Open the private Wasteland Works downloads repository.
  4. Select Draft a new release.
  5. Use the exact release tag shown below.
  6. Drag the ZIP, installer or other project file into the release, wait for it to finish uploading, then select Publish release.
  7. That is all. The private-download gateway will locate the release file when a member requests it.

The tag and file name are case-sensitive and must match GitHub exactly. The original file stays private on GitHub.
